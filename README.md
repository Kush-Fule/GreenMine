# GreenMine

## 🌱 Project Overview
GreenMine is a **web-based MERN application** that enables **mining corporations** to calculate and manage the **carbon footprint of coal mines**. Admins can monitor corporations through emission-level indicators (Green / Yellow / Red).

---

## 🎯 Objectives
- Calculate carbon footprint of mines using **industry-standard formulas**.
- Provide dashboards for mining corporations and admins.
- Simple, realistic, and placement-ready MERN project.

---

## 👥 User Roles
### Admin
- View all mining corporations
- Monitor cumulative emissions
- Delete corporation accounts
- Emission indicators

### Mining Corporation
- Register & log in
- Manage profile and mines
- Calculate footprint per mine
- View analytics and charts

---

## 🗃️ Technology Stack
- **Frontend:** React, Chart.js, Axios, React Router
- **Backend:** Node.js, Express
- **Database:** MongoDB
- **Authentication:** JWT
- **Version Control:** Git & GitHub
